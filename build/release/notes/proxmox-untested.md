**Proxmox VE: the qcow2 is untested on a real Proxmox VE host.** `sneakers-appliance-<version>-amd64.qcow2` is new in this release. CI boots it the way the Proxmox guide sets the VM up (q35, OVMF without pre-enrolled keys, TPM 2.0, VirtIO SCSI single, a VirtIO NIC and the guest agent), and it enrols its Secure Boot keys, comes up with TPM custody and shuts down from the agent there. Nobody has imported it into Proxmox VE itself yet, so treat it as a preview until that test is done. To try it, follow [docs/proxmox-vm.md](https://github.com/Sneakers-PAM/sneakers-appliance/blob/main/docs/proxmox-vm.md).
